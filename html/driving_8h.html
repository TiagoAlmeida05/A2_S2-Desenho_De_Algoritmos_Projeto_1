Marks specified nodes and segments as "visited" or "selected" for route planning.

This function allows the user to specify nodes and segments to be avoided while calculating the route. It will mark the nodes as visited and mark the edges as selected based on the provided input strings.

Parameters
gThe graph containing all the nodes and edges.
avoidNComma-separated list of node IDs to be avoided.
avoidSComma-separated list of edge segments to be avoided.
